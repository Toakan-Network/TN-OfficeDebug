🔍 TN-OfficeDebug

Office.js Debug Tool for IT Professionals

About

A comprehensive diagnostic tool for Microsoft Office Add-ins that displays detailed debug information about the Office environment, document properties, system resources, and more. Built specifically for IT professionals and developers working with Office.js.

Features

Office Environment Host, platform, version, language, and theme information
Document Info Properties, metadata, statistics, and timestamps
Add-in Details Settings, manifest, and license information
System Info Browser, memory usage, screen dimensions, and performance

Quick Install (Office Online)

To use this tool in Microsoft Word Online:

  1. Open Word Online at office.com
  2. Create a new blank document
  3. Go to Insert → Add-ins → Upload My Add-in
  4. Upload the manifest.xml file
  5. Click Show Debug Info in the ribbon

For Developers

Clone and run locally:

git clone https://github.com/Toakan-Network/TN-OfficeDebug.git cd TN-OfficeDebug python3 -m http.server 8080 # Open http://localhost:8080 in your browser
